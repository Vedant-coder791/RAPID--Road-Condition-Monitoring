# RAPID

**Road Analysis using Phone-based Intelligent Detection**

RAPID is an experimental AI-driven road monitoring system that uses smartphone sensors, computer vision, and GPS to detect, assess, and map road conditions.

## Project Goal

The goal of RAPID is to investigate whether commonly available smartphone sensors can be used to estimate road quality without requiring expensive dedicated road-monitoring equipment.
